Falta conectar la base de datos

Esta aplicación necesita los datos de tu proyecto de Supabase para funcionar.

  1. Abre el archivo config.js que está junto a este index.html.
  2. Pega tu Project URL entre las comillas de SUPABASE_URL.
  3. Pega tu anon public key entre las comillas de SUPABASE_ANON_KEY.
  4. Guarda el archivo y recarga esta página.

Los encuentras en Supabase › Settings › API. Revisa instrucciones.txt para el paso a paso completo.
